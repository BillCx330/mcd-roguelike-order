# 麦门大富翁：麦麦套餐锻造记

## 项目介绍

一个带肉鸽事件和程序员梗的麦当劳点餐 Skill。玩家用预算、口味和人数开局，穿过随机事件，获得游戏内战利品，最后锻造套餐方案。HP 是游戏数值；获得餐品补给时会同步展示热量、蛋白质、脂肪和碳水。

基于麦当劳 MCP（`https://mcp.mcd.cn`）开发：路线与剧情由 Skill 随机生成，餐品、营养、优惠、价格、积分和订单事实全部来自 MCP 实时响应。项目包含：

- `SKILL.md`：Skill 源文件。
- `mcd-roguelike-order.zip`：可导入 WorkBuddy 的 Skill 包（发布前将作者字段替换为参赛者 GitHub 用户名）。
- `demo.html`：Agent 工作台风格的单文件试玩原型（样式与脚本全部内联），双击即可玩，发给别人也无需附带其他文件；包含任务侧栏、自然对话、随机房间、回复选项、颜文字排版小画面、积分选择和订单确认，不展示生硬的工具调用卡片。

本项目是参赛者独立开发的非官方作品，不代表麦当劳。麦当劳商标及品牌资产归其权利人所有。

## 目标用户

想快速决定“这顿吃什么”的麦当劳会员、一起点餐的同事和朋友，以及喜欢轻量肉鸽游戏与程序员梗的玩家。

## 安装方法

1. 具备麦当劳 MCP Token：在 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 用手机号验证登录，控制台一键申请。
2. 在 WorkBuddy（或其他支持 Streamable HTTP 的 MCP 客户端）配置麦当劳 MCP Server，配置格式见 `mcp-config.example.json`；把 `YOUR_MCP_TOKEN` 换成自己的 Token，且不要提交到 GitHub。
3. 在 WorkBuddy 导入 `mcd-roguelike-order.zip`（Skill 包；发布前将 `SKILL.md` 的 `author` 字段替换为参赛者 GitHub 用户名）。
4. 在对话中输入“开一局麦门大富翁”，提供预算、想吃什么和人数，也可以说“随机开局”。

## 使用示例

触发方式：对 Agent 说「开一局麦门大富翁」「今天吃什么，帮我决定」「帮我点麦当劳」「帮我领券」等自然说法即可触发；如果只想快速点餐不想玩游戏，说「直接帮我点」会跳过剧情、保留安全确认直接点餐。

> 开一局：3个人，人均30元，想吃鸡肉，路线随机。

> 随机开局：2个人，总预算80元。

> 开局后回复「投掷骰子」推进房间；踩到补给格自动领免费券；抽奖房间可选「虚拟抽奖 / 积分抽奖 / 跳过」；终局看过账单后选「确认生成订单回执」或「只看方案」。

本地试玩：用浏览器打开 `demo.html`，像在 Agent 对话里一样输入预算、口味和人数，或点击快捷开局。原型不会连接账户、领取真实优惠券、扣积分或创建真实订单。

## 玩法

- 开局可以按人均或总额输入预算、口味和人数（支持“两个人人均40想吃辣的”这类自然写法）；路线与普通事件随机生成，也支持全随机开局。
- 每局随机洗牌 5–6 个房间：活动异象、优惠券补给、食材密室、程序员事件、积分抽奖站和隐藏分支；事件与文案从素材池抽取，局内尽量不重复，终局 Boss 也随机（饥饿领主 / 预算巨龙 / 选择困难魔王）。
- 餐品补给可以增加游戏 HP，同时展示 MCP 返回的营养数据；HP 只属于游戏规则。
- 踩中优惠券房间后，按开局提示自动领取当前可领的免费券（无成本操作不打扰玩家）。
- 抽奖房间可选虚拟抽奖、真实积分抽奖或跳过。真实抽奖先展示实际消耗，再等玩家选择；有成本的操作一律先确认。
- 终局由 Skill 本地筛选套餐组合，用 MCP `calculate-price` 核价；玩家确认餐品、总价和配送信息后，才创建待支付订单。预算超支时 Boss 还剩一格血，可带走方案或重新开局。

## 项目结构

- `demo.html`：单文件试玩原型（内联全部样式与脚本），双击即玩，可直接分享。
- `SKILL.md`：Skill 源文件（`mcd-roguelike-order/` 内为打包用副本）。
- `mcd-roguelike-order.zip`：可导入 WorkBuddy 的 Skill 包。
- `CONTEST_DECLARATION.md`、`MCP_INTEGRATION.md`、`mcp-config.example.json`：参赛要求文件。
