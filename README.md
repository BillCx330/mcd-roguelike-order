# 麦门大富翁 · 命运汉堡堡 🎲🍔

## 📖 项目介绍

**基于麦当劳官方 MCP 实时数据的游戏化点餐 Skill，把「今天吃什么」变成一局肉鸽冒险。**

从预算、口味、人数出发，随机房间探索、自动领券、营养同步、积分抽奖三选一，最后锻造出一份可核价、可确认、可下单的真实套餐 —— 吃得开心，也点得明白。

所有餐品、营养、优惠、价格、积分与订单数据均来自麦当劳官方 MCP 的实时响应，Skill 只做查询与玩法编排，不编造任何促销、中奖或账户结果。

## ✨ 三大核心功能

1. 🎲 **随机肉鸽冒险（探索）**

   一句话开局（预算 / 口味 / 人数，或直接「全随机」），每局随机洗牌 5–6 个房间：麦麦补给格、食材密室、程序员事件、积分抽奖站、活动异象、隐藏分支。掷骰推进、事件文案轮换、终局 Boss 随机换人（饥饿领主 / 预算巨龙 / 选择困难魔王）—— 没有两局一样的旅程。

2. 🎫 **免费领券 + 积分三选一（收集）**

   踩到补给格，自动领取当前可领的免费券（无成本操作不打扰）；积分抽奖提供「虚拟抽奖 / 积分抽奖 / 跳过」三选一，真实抽奖会先亮明本次消耗、等你确认才执行。餐品补给加游戏 HP 的同时，原样展示 MCP 返回的热量、蛋白质、脂肪、碳水。

3. ⚔️ **套餐锻造与安全下单（终局）**

   Skill 在本地按预算 / 口味 / 人数筛选候选组合，再用官方 `calculate-price` 逐个核价，给出商品、优惠、配送费、实付金额和营养明细的完整账单；你确认后才创建待支付订单，支付永远由你在官方页面完成。

## 🧠 它的「聪明」体现在哪

- **自然语言开局**：「两个人人均40想吃辣的」「3个人总预算80想吃鸡肉」都能听懂，缺什么就补问一句。
- **随机但不乱来**：随机的是路线、剧情和游戏数值；餐品、价格、优惠、积分全部以 MCP 实时返回为准，剧情绝不冒充真实促销。
- **资产安全熔断**：免费的自动来，有成本的（积分抽奖 / 积分兑换 / 下单）一律先亮成本、后等确认；创建订单前必展示对账账单。
- **纯文本颜文字画面**：打怪血条、汉堡分层、转盘、骑手送餐全是颜文字排版的小画面，真实 Agent 对话里能原样输出，不依赖图片。
- **程序员梗管够**：缓存命中、依赖冲突、CI 全绿、git revert 救午休……梗服务于剧情，点到即止，不尬。

## 📦 安装方法

💡 本项目是一个遵循 Agent Skills 开放规范（`SKILL.md`）的通用 Skill，可被 WorkBuddy、Claude Code / Desktop、Cursor、Kiro、Cherry Studio、Trae、VSCode 等 Agent 工具加载。

前置要求：一枚麦当劳 MCP Token（在 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) 手机号登录后免费申请）。

1. 🔌 在 Agent 工具中配置麦当劳 MCP Server（Streamable HTTP · `https://mcp.mcd.cn`），配置样例见 `mcp-config.example.json`，把 `YOUR_MCP_TOKEN` 换成自己的 Token。
2. 📦 导入 `mcd-roguelike-order.zip`（或直接加载 `SKILL.md`）。
3. 🎮 对话框里喊一声「开一局麦门大富翁」。

⚠️ 安全：Token 只放在本地客户端配置；仓库内全部是环境变量占位符，请勿把真实 Token 提交到任何公开仓库。

## 🕹️ 玩法说明

| 阶段 | 你说 | 发生什么 |
|---|---|---|
| 开局 | 预算 / 口味 / 人数，或「全随机」 | 生成随机路线、初始 HP，预告本局 Boss |
| 探索 | 投掷骰子 | 掷骰走进随机房间，触发事件 |
| 补给格 | （自动） | 免费券自动领取并入包；空柜也有安慰奖 |
| 营养补给 | （自动） | HP +X，并列展示真实热量 / 蛋白 / 脂肪 / 碳水 |
| 抽奖站 | 虚拟抽奖 / 积分抽奖 / 跳过 | 虚拟不扣分；真实抽奖先亮消耗再执行 |
| 终局锻造 | 确认生成订单回执 / 只看方案 | 核价出账单，确认后创建待支付订单 |

## 关于数据真实性

- **真实 Skill**：所有餐品、营养、优惠、价格、积分、抽奖与订单状态均来自 MCP 实时响应；工具没有返回的信息一律写「暂无数据」，不用剧情补齐。官方工具说明未承诺中奖概率，虚拟抽奖只有在 MCP 提供可验证概率时才会采用，否则明确标注为游戏内概率。
- **试玩原型**：`index.html` 中的时间、积分、优惠、餐品、抽奖和订单全部是模拟演示数据，页面顶部有统一声明，不连接任何账户、不创建真实订单。
