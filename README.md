# 麦门大富翁 · 命运汉堡堡 🎲🍔

> **一局肉鸽冒险，终结「今天吃什么」的无限 while 循环。**
> 基于麦当劳 MCP 的游戏化点餐 Skill —— 玩着玩着，餐就点好了。

## 📖 项目介绍

麦当劳 MCP 什么都会：查菜单、算价格、领券、看积分、下订单。可如果只是问答，那和满大街的「查券脚本」有什么区别？😤

**《麦门大富翁 · 命运汉堡堡》** 把一次点餐决策变成一场肉鸽冒险：掷骰子走房间、开补给柜领券、和程序员 Boss 对线、转命运转盘，最后在「终极锻造炉」里把战利品炼成一份真·可下单的套餐。

🎮 **游戏是包装，能力是真的** —— 餐品、营养、优惠、价格、积分、订单全部来自麦当劳 MCP 实时响应。

| 爽点 | 说明 |
|---|---|
| 🎲 随机冒险 | 5–6 个房间每局洗牌、事件文案轮换、Boss 随机换人，没有两局一样的旅程 |
| 💰 实在收益 | 免费券自动领、营养同步看、预算有兜底，玩完直接能下单 |
| 🛡️ 资产安全 | 抽奖 / 兑换 / 下单一律先亮成本等确认；免费的才自动来 |

## 🚀 安装方法

1. 🎫 申请麦当劳 MCP Token：到 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 手机号验证登录 → 控制台一键申请
2. 🔌 在 WorkBuddy（或其他支持 Streamable HTTP 的 MCP 客户端）配置麦当劳 MCP Server，格式见 `mcp-config.example.json`（`YOUR_MCP_TOKEN` 换成自己的 Token，别提交到 GitHub！）
3. 📦 在 WorkBuddy 导入 `mcd-roguelike-order.zip`
4. 🎮 对话框里喊一声「开一局麦门大富翁」

只想快速点餐不想玩？说「直接帮我点」，跳过剧情但保留所有安全确认。😌

## 🕹️ 玩法

- 🎯 **开局**：预算（人均/总额）、口味、人数随便说，支持"两个人人均40想吃辣的"这种大白话；也可以全随机
- 🗺️ **探索**：随机洗牌 5–6 个房间 —— 麦麦补给格、食材密室、程序员事件、积分抽奖站、活动异象、隐藏分支
- 🎫 **领券**：免费券踩格自动领（无成本不打扰）；抽奖三选一「虚拟 / 积分 / 跳过」，真实抽奖先亮消耗再等你选
- 🍔 **营养**：餐品补给加游戏 HP，同时原样展示 MCP 返回的热量、蛋白质、脂肪、碳水
- ⚔️ **终局**：Skill 本地筛组合 → `calculate-price` 核价 → 你看过账单确认后才创建待支付订单。预算超支？Boss 还剩一格血，带走方案或换个构筑再来
